## Step 1: Generate an Application Password in WordPress

To use the REST API securely, you need an application password. Follow these steps to generate one:

### 1. Log into WordPress Admin

Go to your WordPress Admin Panel at `yourdomain.com/wp-admin` and log in with your admin credentials.

### 2. Navigate to Your Profile Settings

From the left sidebar, go to **Users** > **Profile** (or **Your Profile** if you're logged in as an admin).

### 3. Generate Application Password

Scroll down to the **Application Passwords** section. It’s located near the bottom of the page, below the **Biographical Info** section.

1. Enter a name for your application password. This can be any name that helps you identify what the password is used for (e.g., **“ChatGPT API”** or **“Mobile App”**).
2. After entering the name, click the **Add New Application Password** button.

WordPress will generate a unique application password for you. **Copy this password immediately** as it will not be shown again. Store it securely.
